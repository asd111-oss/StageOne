# StageOne — сайт

Статический сайт StageOne. Главная страница — `index.html`.

## Страницы
- `index.html` — главная (направления, продукты, контакты, cookie-баннер)
- `company.html` — О компании
- `academy.html` — StageOne Academy
- `privacy.html` — Политика конфиденциальности

## Ресурсы
- `base.css` — стили
- `base.js` — скрипты (анимации, навигация, фон)
- `favicon.svg`, `icon-max.png`, `icon-telegram.png`

Шрифты подгружаются через Google Fonts (CDN), отдельные файлы не нужны.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите все файлы из этой папки в корень.
2. Settings → Pages → Source: ветка `main`, папка `/root`.
3. Сайт откроется на `index.html`.
