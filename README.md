# StageOne — сайт

Статический сайт StageOne. Главная страница — `index.html`.

## Страницы

- `index.html` — главная (направления, продукты, контакты, cookie-баннер)
- `company.html` — О компании
- `academy.html` — StageOne Academy
- `privacy.html` — Политика конфиденциальности
- `articles/index.html` — публичный список утверждённых материалов
- `articles/feed.json` — машинная лента карточек статей
- `articles/<slug>/index.html` — отдельная статическая статья

## Ресурсы

- `base.css` — стили
- `base.js` — скрипты (анимации, навигация, фон)
- `favicon.svg`, `icon-max.png`, `icon-telegram.png`

Шрифты подгружаются через Google Fonts (CDN), отдельные файлы не нужны.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите все файлы из этой папки в корень.
2. Settings → Pages → Source: ветка `main`, папка `/root`.
3. Сайт откроется на `index.html`.

Контент-завод не пишет в `main` напрямую: для каждой утверждённой версии он создаёт
отдельную ветку и pull request. Публикация происходит только после проверки и merge.

## Проверка

Перед pull request выполните `npm run verify`. Команда проверяет синтаксис клиентского
скрипта, структуру ленты статей и локальные ссылки без установки зависимостей.
